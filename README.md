A one-line tombstone epitaph of famous last words, written by `main.ts` to
`/output/entry.txt` (program/v1). The line:

> My last words were "I've done this a thousand times" — the thousand-and-first time had other plans.

## Usage

    node main.ts

Writes the entry to `/output/entry.txt` and prints it with its character count.
Node 22, standard library only.
